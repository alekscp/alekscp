Security model

Private by default.

Dashboard and API surfaces should stay private unless public exposure is deliberately designed. Tailscale is the preferred private access path. A reverse proxy can be added when a public domain, TLS, and access controls are required.

The goal is simple: your agent runs on infrastructure you control, with enough operational documentation to restart, inspect, back up, and hand off the system.
